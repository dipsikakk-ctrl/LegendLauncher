LEGEND — сайт лаунчера Minecraft
================================

КАК ЗАПУСТИТЬ
1) Установи Node.js (nodejs.org, LTS)
2) В папке проекта:   npm install
3) Запуск:            npm start
4) Открой:            http://localhost:8765

ФАЙЛ КЛИЕНТА ДЛЯ СКАЧИВАНИЯ
Положи установщик (например, legend-setup.exe) в папку private/.
Сервер отдаёт его только зарегистрированным пользователям —
прямая ссылка на файл из интернета не работает.

ПОЧТА (коды подтверждения и сброса пароля)
Настройки SMTP лежат в файле .env (mail.ru).
ВАЖНО: .env содержит пароль почты — не заливай его в публичный
репозиторий (в .gitignore он уже добавлен). На хостинг просто
положи .env рядом с сервером.

ЗАЩИТА
- пароли хранятся только в виде scrypt-хеша с солью
- коды писем одноразовые, живут 10 минут, сгорают после 5 попыток
- лимиты запросов (антибрутфорс) по IP и e-mail
- сессии в HttpOnly+SameSite cookie, служебные файлы из сети закрыты
- безопасные заголовки (CSP, X-Frame-Options и др.)

ХОСТИНГ
Нужен хостинг с поддержкой Node.js (VPS, Render, Railway...).
Загрузи проект, заполни .env, выполни npm install && npm start.

GITHUB PAGES (статический режим)
Залей файлы в репозиторий и включи GitHub Pages (ветка main, корень).
Файл .nojekyll уже лежит в проекте — он отключает сборку Jekyll,
которая ломает сайт.
Сам определяет, что сервера нет, и переключается: аккаунты хранятся
в браузере, а коды показываются прямо в окне (отправить письмо без
сервера невозможно). Выглядит и работает так же.
Ссылку на скачивание лаунчера впиши в js/main.js:
    const CLIENT_DOWNLOAD_URL = 'https://github.com/user/repo/releases/download/v1/legend-setup.exe';
